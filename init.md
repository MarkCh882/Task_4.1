## git init

**git init** - создаёт в текущем каталоге новый подкаталог с именем .git.

Чтобы создать в текущем каталоге новый подкаталог с именем .git, содержащий все необходимые файлы репозитория — структуру Git репозитория, используйте коменду:

---

```bash=
git init
```
